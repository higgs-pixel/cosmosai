# Contributing to COSMOS AI

Thank you for contributing to COSMOS AI.

COSMOS AI is an AI-powered space exploration and education platform using real space data, research, and modern web technologies.

## Tech Stack

- Next.js
- TypeScript
- Tailwind CSS
- Supabase
- NASA APIs
- OpenAI / AI integrations

## Contribution Rules

Before contributing:

1. Do not push directly to `main`.
2. Create a separate branch for every task.
3. Never commit API keys, passwords, `.env`, or private credentials.
4. Open a Pull Request for review.
5. Wait for approval before merging.
6. Keep communication professional and respectful.

## Branch Naming

Use clear branch names:

```text
feature/login-system
feature/dashboard-ui
fix/navbar-bug
docs/readme-update
refactor/api-service
